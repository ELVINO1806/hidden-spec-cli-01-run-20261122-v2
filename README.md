mend is a command-line tool that applies an edit an AI model wrote to a tree of text files. It reads all four formats models write — unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON tool calls — finds the lines each edit names at the first of three matching tiers, and writes every change or none, printing what changed or why an edit failed.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
